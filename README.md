# LaTeX Thesis Template

A LaTeX template for writing a Master's thesis at Hochschule für Nachhaltige Entwicklung Eberswalde (HNEE) and Warsaw University of Life Sciences (WULS) in the Master's program Forest Information Technology.

This repository provides a structured and customizable LaTeX project with predefined formatting, bibliography management, and reusable components to simplify the thesis-writing process.

## Formatting Guidelines

The layout and formatting of this template follow the official thesis guidelines applicable as of 2026.

Please note that requirements may change over time. Before using this template, please independently verify whether the formatting guidelines are still up to date and check for any new or revised requirements by HNEE and WULS. An adjustment to the template may be necessary to ensure compliance with the latest regulations.

## Document Versions

This project contains two separate main LaTeX files, each of which generates a different version of the thesis document:
- `master_thesis_hnee.tex`
- `master_thesis_wuls.tex`

Both files need to be compiled separately to generate the respective versions.

To compile the thesis using `latexmk`, run:
```bash
latexmk -pdf master_thesis_hnee.tex
```
